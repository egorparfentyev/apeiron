# Вектор — личная траектория

Нативный проект приложения для iPhone с iOS 26+. Первая версия для студента 3-го курса МФТИ: физика и фотоника, работа в лаборатории, DS/CV/ML/AI, английский B1 с акцентом на речь, путешествия, доход и стартапы.

**Статус:** исходный проект готов для сборки в Xcode. На этой машине установлен только Command Line Tools, поэтому iOS-сборка, установка и визуальная проверка на симуляторе не выполнены. Это не установленное приложение и не подписанный IPA.

## Что реализовано

- Пять экранов: Сегодня, Цели, Календарь, Прогресс, Опора.
- Планирование дел на выбранный день, редактирование, удаление, длительность, заметка о результате; статусы «В плане», «Сделано», «Не сделал». Будущие дни доступны для планирования.
- Десять персональных целей на полгода, год и 5–10 лет. Сроки отсчитываются от первого запуска. Этапы, смысл цели и план на случай препятствий редактируются.
- Привычки по дням недели, маленький старт и привязка к существующему действию. Отдельные отметки выполнения, пропуска и отдыха. Завершение привычки сохраняет прошлую историю.
- Локальные объяснимые подсказки по русским и английским словам. Пользователь выбирает направление; статус не выводится из текста. «Не сделал ML» не засчитывается как достижение.
- Дневник с сохранением по датам; темы заметки видны отдельно от результатов.
- Статистика за 7 и 30 дней, Swift Charts, выполненные дела по направлениям и рекомендации для еженедельного обзора.
- Шесть проверенных карточек научных возможностей. Подтверждённые даты отделены от наборов без даты. Собственные события и добавление через системный редактор календаря iPhone.
- Небольшая библиотека принципов из материалов авторов/издателей пяти книг; ссылки на источники.
- Локальное ежедневное уведомление по желанию, экспорт и восстановление JSON.
- Локальное хранение с атомарной записью; ошибки записи не считаются успехом. При повреждении файла приложение блокирует изменения и позволяет восстановить копию, не перезаписывая повреждённый оригинал.

## Как запустить на iPhone

1. Установить полный **Xcode с iOS SDK 26 или новее**.
2. Открыть `Vector.xcodeproj`, выбрать схему **Vector**.
3. Для первого просмотра выбрать iPhone Simulator с iOS 26+ и нажать Run.
4. Для своего iPhone: в **Signing & Capabilities** выбрать свою Team, при необходимости изменить Bundle Identifier на уникальный. Подключить iPhone, включить Developer Mode и выбрать его как устройство запуска.
5. Нажать Run. Уведомления запрашиваются только по кнопке в настройках. События календаря сохраняются через системный экран с вашим подтверждением.

Apple ID, подпись и устройство необходимо настроить в вашем Xcode. Подпись, TestFlight и App Store в эту поставку не входят.

## Рекомендуемый первый вечер

1. Откройте «Цели», сократите этапы до реалистичных и уточните ближайшие сроки.
2. Добавьте одно дело: «Записать 2 минуты речи на английском о своём проекте». Выберите предложенное направление и связанную цель.
3. Оставьте режим «Загруженный день», если идут пары или зачёты.
4. В конце дня отметьте результат, запишите причину переноса, если нужно. Сохраните вечернюю заметку кнопкой.
5. Раз в неделю просмотрите прогресс; раз в месяц сравните запись английской речи с предыдущей и пересмотрите этапы.

## Единая архитектура

**SwiftUI + Observation + Foundation/Codable + Swift Charts + EventKitUI + UserNotifications.** Сторонних зависимостей, серверов и ключей API нет. SwiftUI использует системные компоненты iOS 26, которые поддерживают актуальный внешний вид системы; карточки используют стандартные материалы. Dynamic Type и светлая/тёмная тема наследуются от системы.

- `Core.swift` — модель данных, календарные правила, классификатор и расчёты.
- `Seed.swift` — персональный стартовый план, каталог и материалы.
- `Store.swift` — единая точка изменений и сохранения.
- Остальные Swift-файлы — экраны и стандартные системные интеграции.

Для небольшого персонального набора данных выбран один версионированный JSON в Application Support, а не несколько хранилищ. SwiftData рассматривалась: её имеет смысл использовать при росте объёма и появлении сложных выборок. Здесь Codable достаточно, его логика проверяется без iOS SDK. Запись целого файла означает, что очень большие истории потребуют пересмотра хранения.

Ключевые слова — управляемая локальная эвристика, а не LLM. Короткие сокращения (AI, ML, DS, CV) сопоставляются с отдельными словами, длинные русские основы — с началом слова. Неоднозначные темы предлагаются вместе; итоговый выбор остаётся за пользователем.

## Проверка

Запустить проверки логики из папки проекта:

```sh
swiftc Vector/Core.swift Vector/Seed.swift Vector/Store.swift Tests/CoreTests.swift -o /tmp/vector-core-tests
/tmp/vector-core-tests
```

Полная сборка после установки Xcode:

```sh
xcodebuild -project Vector.xcodeproj -scheme Vector -sdk iphonesimulator -destination 'generic/platform=iOS Simulator' CODE_SIGNING_ALLOWED=NO build
```

Результаты и оставшиеся проверки: [VALIDATION.md](VALIDATION.md).

## Границы первой версии

- Нет автоматического обновления каталога, подключения личного календаря на чтение и автоматического подбора свободных окон по парам. Нагрузка и даты дел задаются вручную.
- Нет облачной синхронизации, чата с языковой моделью, анализа произношения, интеграций с LMS/Health или фонового агента. Предложенные советы локальные и основаны на отмеченных действиях.
- Не измеряет реальные деньги, уровень английского или научную квалификацию автоматически. Эти результаты проверяются этапами целей.
- Каталог — снимок на 28.10.2026. Условия допуска, финансирование и документы нужно уточнять в каждом официальном источнике. Новые даты не прогнозируются.
- Интерфейс и системные разрешения ещё требуют проверки на настоящем iPhone. App Store-публикация также потребует иконки, метаданных, скриншотов и проверки релизных требований.

Источники, готовые решения и причины выбора: [RESEARCH.md](RESEARCH.md).
