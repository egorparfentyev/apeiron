# Апейрон

Личный ежедневник для iPhone с задачами, привычками, целями, календарём и маршрутами для английского, фотоники и стартапов.

[Открыть веб-версию](https://vector-personal-path-rm.upiterj3.chatgpt.site/)

- `dist/` — актуальная веб-версия, включая стартовые материалы и иконки.
- `tests/` — проверки ежедневника, маршрутов, запуска и офлайн-кэша.
- [`ios/`](ios/README.md) — исходники раннего прототипа для iOS 26+, исследовательские материалы и инструкции для Xcode. Прототип назывался «Вектор».

Для локального запуска из корня репозитория выполните:

```sh
python3 -m http.server 8000 --directory dist
```

Откройте http://localhost:8000. На iPhone откройте опубликованную версию в Safari и выберите «Поделиться» → «На экран Домой». Данные хранятся в браузере. Резервную копию можно выгрузить из настроек.

Проверки веб-версии (Node.js 22+):

```sh
node --test tests/*.test.mjs
```
