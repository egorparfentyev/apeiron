# Кайрос

Личный ежедневник для iPhone с задачами, целями, календарём и маршрутами для английского, фотоники и стартапов.

[Открыть веб-версию](https://apeiron-daily.web.app/) · [Резервный адрес Firebase](https://apeiron-daily.firebaseapp.com/)

- `dist/` — актуальная веб-версия, включая стартовые материалы и иконки.
- `tests/` — проверки ежедневника, маршрутов, запуска и офлайн-кэша.
- [`ios/`](ios/README.md) — исходники раннего прототипа для iOS 26+, исследовательские материалы и инструкции для Xcode. Прототип назывался «Вектор».

Для локального запуска из корня репозитория выполните:

```sh
python3 -m http.server 8000 --directory dist
```

Откройте http://localhost:8000. На iPhone откройте опубликованную версию в Safari и выберите «Поделиться» → «На экран Домой». Данные хранятся в браузере. Резервную копию можно выгрузить из настроек.

Проверки веб-версии (Node.js 22+):

```sh
node --test tests/*.test.mjs
```

### Публикация и перенос данных

Веб-версия размещается на Firebase Hosting и открывается без учётной записи. Конфигурация публикует только каталог `dist/` на сайте `apeiron-daily`. Укажите идентификатор проекта Firebase в переменной `FIREBASE_PROJECT_ID`.

```sh
npx firebase-tools deploy --only hosting --project "$FIREBASE_PROJECT_ID"
```

Задачи, цели и отметки привязаны к адресу в браузере. Чтобы перенести их со прежнего адреса, скачайте резервную копию через «Настройки → Ваши данные», затем добавьте этот файл через тот же раздел на новом адресе. Используйте один адрес Firebase для повседневной работы.
